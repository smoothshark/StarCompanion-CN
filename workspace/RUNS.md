每个批次通常包含：

| 路径 | 说明 |
|---|---|
| `run.json` | 批次模式、manifest 与结果路径 |
| `manifests/*.json` | 给每个 Codex 子任务的输入清单 |
| `results/*.ndjson` | 子任务生成结果 |
| `logs/*.log` | Codex CLI 标准输出和错误日志 |
| `merge-report.json` | 当次合并数量、无效条目和完成状态 |

历史报告中的 `codex_partial` 只表示“该次批次仍有失败项”。这些失败项后来由后续批次补齐，不等于当前主数据仍缺失。
